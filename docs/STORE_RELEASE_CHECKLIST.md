# ImageFlow Store Release Checklist

Datum: 2026-05-08

## Noch nicht releasefaehig

ImageFlow ist in der Bootstrap-Phase und nicht fuer den App Store freigegeben.

## Vor Release

- Lizenz final pruefen.
- Datenschutzdokumentation finalisieren.
- Sicherheitsmodell pruefen.
- UI auf Desktop und Mobile testen.
- Migrationen auf sauberer Nextcloud-Instanz testen.
- Keine Secrets oder Testpasswoerter im Repository.
- Browser-Tests und Self-Check bestehen.
- Restore-Prozess praktisch getestet.
- Schreiboperationen mit Checksummenmodus verifiziert.
